# Real-Time Chat Application

A full-stack real-time chat application using React, Node.js, Express, MongoDB, JWT, and Socket.IO.

## Features
- Secure JWT registration/login
- One-to-one messaging
- Group chat rooms
- Real-time messages with Socket.IO
- Online/offline status
- Basic notifications
- REST APIs

## Requirements
- Node.js 18+
- MongoDB running locally or MongoDB Atlas

## Setup

### Backend
```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

### Frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

Open the frontend URL shown by Vite.

Default backend URL: `http://localhost:5000`
